# P6.5 — Painel do Professor — v12.9

## Objetivo

Consolidar acompanhamento de sala, detalhe individual, liberação pedagógica e explicação guiada no Console Professor, sem mover respostas privadas ou autoridade para o frontend do aluno.

## Acompanhamento

- filtro de turma;
- alunos no escopo do professor;
- atividade/progresso mais recente quando fornecido pelo `staff-dashboard`;
- “Ativo agora” somente com sessão/heartbeat inferior a 90 segundos;
- ausência de heartbeat não é apresentada como presença;
- indicadores de alunos, ativos, em atividade e atenção;
- atualização silenciosa a cada 15 segundos apenas com a página visível;
- seleção do aluno leva ao fluxo individual já existente.

## Aula guiada

O botão só aparece quando o backend devolve `teacher_reference.solution_payload.files`. O conteúdo não é embutido no bundle aluno.

O professor pode:

1. escolher o arquivo;
2. avançar/voltar etapas;
3. reproduzir automaticamente;
4. acompanhar o código sendo revelado progressivamente;
5. usar explicações contextuais para HTML, CSS, JavaScript e Python;
6. respeitar `prefers-reduced-motion`.

## Segurança

- nenhuma `service_role`;
- nenhuma recompensa ou liberação criada pelo modo guiado;
- gabarito continua vindo de `agv-teacher-activity`;
- escopo de turma continua server-side;
- o aluno não recebe a UI nem os dados privados do modo professor.

## Backend

Sem SQL, migration ou nova Edge Function nesta fase.

- suíte `core/tests/*.test.mjs`: 31/31 testes aprovados;

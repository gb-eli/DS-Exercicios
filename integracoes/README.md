# Integrações auxiliares

## Exercícios Práticos DS v0.14.1 — P3

O ZIP `exercicios-praticos-ds-v0.14.1-P3.zip` é cumulativo sobre v0.14.0 e corrige a herança dos recursos de apoio configurados por turma:

- `allow_html_base`
- `allow_css_base`
- `allow_js_base`
- `allow_extra_hints`
- `allow_guided_support`

A precedência continua sendo **aluno → turma**. O starter HTML/CSS/JS só é aplicado na primeira criação dos arquivos e nunca sobrescreve arquivos já salvos.

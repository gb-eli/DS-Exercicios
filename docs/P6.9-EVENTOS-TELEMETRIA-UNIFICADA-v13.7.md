# P6.9 — Eventos e Telemetria Unificada — v13.7

## Objetivo
Transformar `activity_progress` e `progress_events` já existentes em métricas úteis sem criar autoridade nova no frontend.

## Aluno
O Hub de plataformas consulta somente dados do próprio usuário permitidos por RLS e exibe última atividade oficial, atividades concluídas, eventos dos últimos 7 dias e dias ativos observados.

## Tempo
Não é estimado a partir de eventos espaçados. Tempo só deve ser exibido quando existir evidência confiável de sessão (início/fim/heartbeat).

## Admin
O Perfil 360º ganhou a aba **Plataformas**, agregando o `activity_progress` que já chega pelo endpoint autorizado `agv-teacher-activity`.

## Segurança
Nenhuma escrita direta foi adicionada. Nenhum XP, moeda, liberação ou conclusão é calculado por esta camada.

## Backend
Esta versão não exige migration ou nova Edge Function. Uma otimização global por turma fica pendente para quando o Supabase ao vivo puder ser revalidado.

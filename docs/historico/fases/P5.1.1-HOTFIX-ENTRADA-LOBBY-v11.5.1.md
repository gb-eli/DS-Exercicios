# P5.1.1 — Hotfix de entrada no Lobby

## Problema
A v11.5 usava uma Content Security Policy com `script-src 'self'`, mas `lobby/assets/supabase.js` importa o SDK Supabase fixado em `https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2.111.0/+esm`. O navegador bloqueava o módulo, impedindo a inicialização do login.

## Correção
- CSP permite apenas `self` e `https://cdn.jsdelivr.net` para scripts.
- O SDK continua fixado na versão 2.111.0.
- `assets/boot.js` passa a carregar o Lobby e mostra uma mensagem de erro útil caso um módulo falhe.
- Nenhuma alteração de banco ou Edge Function é necessária.

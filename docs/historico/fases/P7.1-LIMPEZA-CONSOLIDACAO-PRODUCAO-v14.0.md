# P7.1 — Limpeza e Consolidação de Produção — v14.0

## Objetivo

Reduzir cópias históricas publicadas em `sistemas/` sem quebrar as URLs-raiz já distribuídas aos alunos.

## Estratégia aplicada

- mantidas as 10 plataformas canônicas da P6.7;
- 13 diretórios históricos foram convertidos em **stubs de compatibilidade**;
- cada stub mantém `index.html` na URL antiga e redireciona para a rota canônica;
- `query string` e `hash` são preservados pelo redirecionamento;
- nenhum banco, RLS, Edge Function, XP, carteira ou autoridade pedagógica foi alterado;
- criado `core/catalog/legacy-routes-v14.0.json` para documentar aliases;
- Hub raiz e Painel do Aluno passaram a consumir `platform-integration-v14.0.json`.

## Rotas consolidadas

CTF: 3 versões históricas → `sistemas/02-ctf-ds/ctf/index.html`.

Planetário: `universo-ds` → `universods/index.html`.

Desafio DS: 7 árvores históricas → `desafio 33/index.html`.

Fliperama: 2 árvores históricas → `flipds/index.html`.

## Limite consciente

A compatibilidade garantida nesta fase é para a **URL-raiz/index.html** das versões históricas. Favoritos apontando diretamente para assets ou páginas internas de versões antigas não são tratados como rotas públicas estáveis.

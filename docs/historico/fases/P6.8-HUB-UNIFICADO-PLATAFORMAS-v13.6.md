# P6.8 — Hub Unificado das Plataformas — v13.6

## Objetivo
Transformar o painel do aluno e o HUB raiz em catálogo único das plataformas integradas ao AGV Core.

## Implementado
- Catálogo canônico v13.6 com categoria, ícone, público e descrição.
- Seção **Suas plataformas** no painel do aluno.
- Filtros: Para minha turma, Todas, Favoritas e Recentes.
- Busca local por nome/categoria/descrição.
- Favoritos e recentes em `localStorage`, apenas para UX.
- Progresso percentual somente quando há dados oficiais suficientes (lab da própria turma).
- Demais plataformas exibem `Progresso sincronizado`, sem percentual inventado.
- HUB raiz também consome o catálogo canônico.

## Segurança
O catálogo é navegação. Não concede XP, moeda, liberação ou conclusão. Favoritos/recentes não são autoridade.

## Backend
Nenhuma migration ou Edge Function nova é necessária.

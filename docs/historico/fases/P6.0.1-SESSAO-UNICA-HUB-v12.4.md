# P6.0.1 — Sessão Única + HUB raiz — v12.4

Data: 15/08/2026
Base: v12.3 / P6.0 Auditoria Geral do Ecossistema

## Objetivo

Remover o Lobby como rota obrigatória e estabelecer uma única sessão Supabase reutilizável entre Hub, Atividades, Lobby, Console Professor e Administração.

## Implementado

- `/index.html` virou HUB responsivo; não existe mais redirect automático para `/lobby/`.
- Atividades e Lobby ficam disponíveis diretamente no Hub.
- Cards de Professor/Admin são exibidos conforme o papel do perfil autenticado.
- Nova camada `core/session/agv-session.js` usa a chave padrão `sb-<project>-auth-token` do Supabase.
- Refresh automático por `refresh_token` antes de considerar a sessão perdida.
- Admin deixou de manter lógica própria de leitura/expiração do token e usa a camada compartilhada.
- Console Professor deixou de usar `sessionStorage` privado e passa a reutilizar a sessão global.
- Um perfil sem escopo de professor pode abrir o Console e receber “sem permissão” sem perder a sessão global.
- Logout explícito encerra a sessão compartilhada.
- Atividades/Admin/Professor receberam atalhos para retornar ao Hub.
- Primeiro acesso de aluno pelo Hub mantém a regra e-mail institucional + CGM; staff continua sem autocadastro.

## Segurança

- Nenhuma `service_role`/secret key foi adicionada ao navegador.
- Hub possui CSP restrita a recursos locais e conexão ao projeto Supabase.
- Autorização continua sendo validada no backend/RLS/Edge Functions; o Hub apenas roteia interfaces.
- Não houve mudança em recompensa, liberação, progresso, RLS ou authority econômica.

## Banco / Edge Functions

Nenhuma migration e nenhum deploy de Edge Function são necessários nesta fase.

# P6.2 — Central de Segurança e Alertas — v12.6

## Objetivo
Transformar a aba Segurança do Admin Central em uma tela operacional para triagem de incidentes, sem ampliar permissões do navegador.

## Entregue
- KPIs de eventos abertos, críticos, altos, rate limit e geolocalização inconclusiva.
- Alerta prioritário para eventos com `risk_code = outside_parana`.
- Filtros por severidade, categoria e busca textual.
- Cartões com usuário, evento, IP, localização, ASN/rede, dispositivo/navegador e código de risco.
- Reconhecimento individual de evento via `security-telemetry / admin_ack`.
- Exportação CSV do recorte filtrado para auditoria administrativa.
- Auto-refresh também na tela Segurança quando ela está visível.
- Layout responsivo para celular e tablet.

## Regra de localização
Acesso cuja geolocalização server-side indique fora do Paraná é tratado como **CRÍTICO** para revisão. Geolocalização ausente/inconclusiva permanece como sinal inconclusivo e não é classificada automaticamente como ataque.

## Segurança
- Nenhuma `service_role` no frontend.
- Nenhuma recompensa, XP ou benefício pode ser concedido pela Central.
- Nenhuma nova escrita direta em tabelas sensíveis foi criada.
- Reconhecimento de eventos continua passando pela Edge Function existente.
- Sem mudança de schema, migration ou Edge Function nesta fase.

## Limitação desta execução
O conector Supabase ficou indisponível durante a implementação. O frontend foi construído sobre os contratos/Edge Functions já empacotados na v12.5. Nenhuma alteração live foi feita sem verificação.

# F94.12 — PATCH Vehicle Core V2 + preparação Rapier

Base obrigatória: **F94.11** (`AGV-WORLD-F94.11-QUALIDADE-GRAFICA-ASSET-STREAMING-V2-v14.10.8.96`).

Este patch unifica o núcleo de veículos do Campus e dos rovers Lua/Marte, adiciona contrato comum de veículo, adapter de física cinemático, preparação opcional para Rapier, protocolo de rede V2 e cache `stage75-f9412-vehicle-core`.

## Não faz

- não ativa Rapier como dependência de produção;
- não altera Supabase/migrations/Edge Functions;
- não torna todo veículo cenográfico do Vale/Militar dirigível;
- não instala Colyseus.

Para base desconhecida ou com patches aplicados fora de ordem, use o ZIP completo da F94.12 em vez deste PATCH.

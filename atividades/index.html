Primeiro acesso

Crie sua senha pessoal

Por segurança, o CGM é apenas uma senha temporária. Defina uma nova senha para liberar os exercícios.

• pelo menos 8 caracteres • pelo menos uma letra • pelo menos um número

Importante

Não reutilize seu CGM

Sua senha deve ser pessoal. Não compartilhe com colegas e evite usar o mesmo código de outros serviços.

Antes de começar

        
Durante esta atividade, o sistema registra eventos necessários para acompanhamento pedagógico e segurança. Trocas de guia/tela cheia são objetivas; sinais de DevTools e entrada anormal são apenas heurísticas para conferência do professor.

        

        

          O que fica registrado
          sessão, exercício atual, arquivo/cursor, IP visto pelo servidor e eventos de segurança. O professor pode acompanhar e editar o código ao vivo.

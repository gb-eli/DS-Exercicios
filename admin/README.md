# DS Exercícios — Administração

Painel administrativo v9.

Acesse `admin/index.html` em ambiente HTTP/HTTPS. O painel exige conta `admin` ou `super_admin` no Supabase central.

Principais contratos:

- `staff-dashboard`
- `supervision`
- `admin-roster`
- `admin-profile-user`
- `agv-teacher-activity`

Não há service key no navegador.

Veja `docs/ADMIN-P0-P1-P2-v9.md` para o escopo e as limitações.

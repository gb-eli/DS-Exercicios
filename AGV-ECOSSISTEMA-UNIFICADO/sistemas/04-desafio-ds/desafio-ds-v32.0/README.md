# Desafio DS v32.0

Plataforma educacional estática para GitHub Pages, com Modo Guiado, perfis locais protegidos, EduAuth offline, Classroom por disciplina, Central de Código e integração ao ecossistema DS.

## Estrutura atual

- 4 grupos de estudantes.
- 7 disciplinas.
- 114 aulas ativas.
- 121 IDs históricos preservados.
- 70 pacotes técnicos.
- Tempo mínimo de 10 minutos e duração prevista de até 40 minutos.

## Novidades da v32

- Código coletivo de oito números válido por uma hora e solicitado somente no início da aula.
- Nenhuma autenticação adicional durante as etapas normais.
- Plataformas externas exibidas pelo nome, com envio de comprovante pelo aluno.
- Link do GitHub solicitado somente quando a aula exigir entrega de código.
- Comprovante final com aluno, horários, atividades, logs, arquivos e links, pronto para salvar em PDF.
- Áreas clicáveis e responsividade revisadas para celular, tablet e Chromebook.

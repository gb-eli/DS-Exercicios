# Desafio DS v25.0

Plataforma educacional totalmente front-end para GitHub Pages, com Desafio DS, diagnóstico completo, Modo Guiado, perfis locais criptografados, EduAuth Offline e Central de Código.

## Publicação

1. Extraia o ZIP público.
2. Envie todo o conteúdo para a raiz do repositório.
3. Ative GitHub Pages na branch desejada.
4. Abra a URL publicada em janela anônima.
5. Teste termo, perfil, EduAuth, desafio, Modo Guiado, exportação e Classroom.

## Recursos da v25

- termo obrigatório e versionado;
- política de privacidade;
- aviso de simulações fictícias;
- manifesto de permissões;
- extrato de XP com reconciliação;
- proteção de importações;
- funcionamento offline após o primeiro carregamento;
- 88 aulas guiadas preservadas;
- 52 aulas com Central de Código;
- EduAuth Offline;
- perfis criptografados em IndexedDB.

## Arquivos privados

Não publique a pasta `PROFESSOR_PRIVADO_NAO_PUBLICAR` nem chaves administrativas.

## Limitações

A aplicação não possui backend. Não há sincronização automática, confirmação real de entrega no Classroom ou segurança equivalente a um servidor autoritativo.

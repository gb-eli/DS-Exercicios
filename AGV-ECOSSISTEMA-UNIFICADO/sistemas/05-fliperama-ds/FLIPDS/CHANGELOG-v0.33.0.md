# Changelog — Fliperama DS v0.33.0

## Fase 7.14 — Padronização histórica e educacional

### Conteúdo dos 18 jogos

- ficha educacional padronizada para todas as experiências jogáveis;
- classificação entre reconstrução, jogo autoral, simulador e laboratório;
- fases, mapas, ondas, rodadas ou objetivos organizados como progressão;
- modos de jogo e níveis de dificuldade;
- qualidade gráfica disponível por experiência;
- história e curiosidades;
- controles e passo a passo preservados;
- exemplo curto de JavaScript ou GLSL por jogo;
- pseudocódigo estruturado no painel de lógica.

### Interface

- novo resumo educacional no guia e na prévia do catálogo;
- painéis de História e Código ampliados;
- layout responsivo para celular, tablet e computador;
- exemplos de código escapados antes da inserção no HTML;
- arquivo `education/game-learning.json` preparado para manutenção futura.

### Compatibilidade

- 18 runtimes preservados; bundle ampliado de 105 para 106 módulos com a nova camada educacional;
- saves e regras dos jogos não foram alterados;
- Service Worker atualizado para v0.33.0;
- conteúdo educacional incluído no shell offline.

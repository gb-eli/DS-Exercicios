Como jogar

Computador: WASD ou setas, mouse para olhar, Espaço para pular, Shift para correr, C para agachar, clique esquerdo para quebrar e clique direito para construir.

Celular: joystick esquerdo para mover, joystick direito para olhar e botões para pular, quebrar, construir e consumir.

Aprendizagem: as missões relacionam coleta, construção, chunks, inventário, eventos e renderização com conceitos de Desenvolvimento de Sistemas.

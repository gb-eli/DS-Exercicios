# Conteúdo e fontes — C1.1

## Política editorial

- Todo item possui ao menos uma fonte cadastrada.
- As fontes iniciais são páginas institucionais da NASA.
- Medidas são arredondadas para uso didático.
- Campos aproximados são apresentados com `≈` ou faixa de valores.
- A data `lastReviewed` indica a revisão editorial do catálogo, não a data de publicação da fonte.

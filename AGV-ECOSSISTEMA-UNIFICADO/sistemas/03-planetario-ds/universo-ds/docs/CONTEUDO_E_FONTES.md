## Regras de apresentação

1. Não afirmar que existe uma única linguagem utilizada pela NASA ou por toda a indústria espacial.
2. Diferenciar software de voo, software de solo, análise científica, interfaces e bancos de dados.
3. Não inferir detalhes proprietários não publicados.
4. Identificar Assembly como simulação didática quando não reproduzir uma arquitetura real completa.
5. Tratar lideranças como parte de equipes multidisciplinares, não como autores exclusivos das missões.
6. Revisar periodicamente páginas institucionais que descrevem cargos ou produtos atuais.

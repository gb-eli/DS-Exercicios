# Ordem de upload no GitHub

Para a primeira publicação, envie o pacote completo preservando a estrutura:

1. arquivos da raiz: `index.html`, `404.html`, `.nojekyll`, `service-worker.js`, `package.json`, `README.md`, `CHANGELOG.md` e `LICENSE`;
2. pasta `src/` completa;
3. pasta `public/` completa;
4. pasta `docs/` completa;
5. pasta `scripts/` e `tests/`;
6. pasta oculta `.github/` com o workflow.

Não renomeie nem mova os arquivos antes do primeiro teste no GitHub Pages.

# Ordem de atualização — Fase 23

## Opção recomendada

1. Faça backup do repositório atual.
2. Extraia o pacote incremental.
3. Envie seu conteúdo para a raiz do projeto, preservando os caminhos.
4. Substitua os arquivos existentes quando solicitado.
5. Não exclua os módulos das fases anteriores.
6. Abra `index.html` pelo GitHub Pages e execute o diagnóstico da Fase 23.

## Ordem técnica

1. `src/core/` e `src/data/`;
2. `src/rendering/`;
3. `src/modules/`;
4. `src/app/`, `src/styles.css` e `src/core/modules/ModuleRegistry.js`;
5. `tests/` e `scripts/`;
6. `public/`, `service-worker.js`, `index.html`, `README.md` e documentação.

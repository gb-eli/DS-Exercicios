# Publicação GitHub Pages v0.9.5.1

## Recomendado

Substitua a publicação pelo conteúdo do ZIP `loja-virtual-ds-v0.9.5.1-GITHUB-PAGES.zip`. Esse pacote já exclui arquivos de desenvolvimento.

## Não publicar

- `assets/concepts/`
- `assets/previews/`
- `dev/`
- `tests/`
- `reports/`
- `src/`
- `examples/`
- `lab/`
- `schemas/`
- previews PNG da raiz

## Após a publicação

Envie `sw.js` por último. Abra em janela anônima e confirme `v0.9.5.1`. Se a versão antiga aparecer, remova o Service Worker e limpe os dados do site.

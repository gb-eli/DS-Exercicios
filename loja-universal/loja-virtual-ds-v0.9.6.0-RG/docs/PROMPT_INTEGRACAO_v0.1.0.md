# Prompt de integração — Fundação Loja Virtual DS v0.3.0

Integre o pacote `loja-virtual-ds-v0.3.0` sem recriar o núcleo econômico. Preserve o catálogo, os identificadores dos itens e os contratos de evento. Crie um adaptador da plataforma que envie recompensas por `DSStore.reward(...)`. Não altere o saldo diretamente. Use o catálogo oficial para validar preços. Carregue Loja, Avatar 3D, Animações e Laboratórios sob demanda. Preserve compatibilidade com versões futuras do pacote.

# Pacotes Ultra e Realismo — v0.9.6.0-RG

## Ultra
- Environment map LDR 2048×1024.
- Mapa de microdetalhe 1024×1024.
- Palco 1920×1080.
- Sprite de flare 512×512.
- Reflexão ambiental e detalhe no shader.

## Realismo
- Environment map LDR 2048×1024 com balanço quente/frio.
- Mapa de microdetalhe 1024×1024.
- Palco cinematográfico 1920×1080.
- Sprite bokeh 512×512.
- Clearcoat simulado e reflexão mais intensa.

## Limites honestos
Não há HDR físico, KTX2, sombras projetadas ou modelos 4K exclusivos nesta versão. Os assets são reais e utilizados pelo runtime, mas continuam otimizados para GitHub Pages.

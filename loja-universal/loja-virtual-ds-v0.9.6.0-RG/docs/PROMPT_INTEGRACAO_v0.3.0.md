# Prompt de integração — Loja Virtual DS v0.3.0

Integre o Kit Gráfico Oficial da Loja Virtual DS preservando o catálogo e a carteira existentes. Copie `assets/`, carregue `assets/asset-manifest.json`, use `item.thumbnail` nos cards e `item.vectorPreview` nas prévias. Não embuta as miniaturas em base64. Preserve carregamento sob demanda, caminhos relativos e fallback textual acessível. Não altere IDs de itens nem valores financeiros.

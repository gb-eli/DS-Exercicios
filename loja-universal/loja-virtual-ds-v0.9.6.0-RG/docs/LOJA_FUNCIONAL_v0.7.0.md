# Loja funcional v0.7.0

## Fluxo

Catálogo oficial → oferta assinável → prévia sob demanda → validação → reserva → compra → extrato → inventário → equipar.

A prévia usa o GLB real quando `model3d` está presente. Itens de animação e VFX continuam usando a prévia específica do módulo. O DOM nunca é usado como fonte do preço.

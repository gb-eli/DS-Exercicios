# Prompt de integração — Loja Virtual DS v0.6.0

Integre a Loja Virtual DS v0.6.0 preservando carteira, extrato, inventário, perfil e equipamentos existentes. Copie integralmente `assets/vfx`, `catalog/vfx.json`, `demo/vfx-data.js` e `demo/vfx-engine.js`. Carregue o módulo VFX somente ao abrir a tela de efeitos, uma prévia VFX ou ao reproduzir um item adquirido. Use `assets/vfx/vfx-manifest.json` como contrato. Não permita que a interface equipe um efeito que não exista no inventário validado. Sincronize o modo de qualidade da plataforma com `DSVFX.setQuality(mode)`. Respeite redução de movimento, pausa ao ocultar a aba e botão para interromper o efeito. Para clips corporais, use os IDs do arquivo `assets/avatars/avatar-tech-v1/animations.json`. Preserve os LODs, slots e modelos da v0.5.0. Não carregue todos os efeitos na inicialização.

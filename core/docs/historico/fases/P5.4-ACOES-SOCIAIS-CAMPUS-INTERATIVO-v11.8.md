# P5.4 — Ações Sociais e Campus Interativo — v11.8

Base: v11.7 / P5.3.

## Entregas
- Menu de ações 🎭 para Dançar, Comemorar, Agachar e Parar.
- Atalho `R` no desktop.
- Bancos da Praça Central interativos: aproximar + `E` para sentar; `E` novamente para levantar.
- Poses extras aplicadas tanto ao avatar GLB rigado quanto ao fallback procedural.
- Movimento ou pulo cancela ação local para evitar estados presos.
- Ações novas não criam campos livres no backend. O multiplayer segue aceitando apenas os emotes previamente validados (`wave`, `like`, `spark`).

## Segurança
Nenhuma migration, alteração de RLS ou Edge Function é exigida nesta fase. A camada 3D permanece sem autoridade sobre exercícios, progresso, carteira ou matrícula.

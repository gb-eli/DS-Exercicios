# P8.0 — Validação privada e novo Exercício 04 do 3DS — v14.8

## Objetivo
Neutralizar o conteúdo futuro comprometido da antiga plataforma 3DS e inaugurar a nova sequência com correção automática cujo critério não é entregue ao navegador do aluno.

## Exercícios preservados
- 3DS 01 — preservado.
- 3DS 02 — preservado.
- 3DS 03 — preservado.

## Novo Exercício 04
**Painel de Prioridades com Filtro Interativo**.

O aluno trabalha com `index.html`, `estilo.css` e `script.js` desde o início. As orientações são públicas, mas as regras efetivas e pesos da correção ficam fora do bundle público.

### Entrega
- correção oficial executada pelo backend;
- percentual de 0 a 100;
- mínimo padrão: **80%**;
- 80–99%: entrega aceita com pendências;
- 100%: conclusão automática integral;
- URL `https://github.com/<usuario>/<repositorio>` obrigatória;
- evidência da entrega inclui hashes SHA-256 e revisões dos arquivos salvos.

## Proteção contra vazamento
O frontend conhece somente o enunciado e a informação de que a autoridade é `backend-privado`. O segredo `AGV_PRIVATE_EXERCISE_RULES_V1` não integra este pacote público.

A Edge Function `activity-progress` lê as regras no ambiente do servidor. Sem o segredo, `evaluate`/`submit` falham fechados e o `complete` comum não pode contornar a validação do Exercício 04.

## Conteúdo futuro
As definições públicas do 3DS 05+ foram removidas do manifesto do aluno. O SQL 032 também foi preparado para torná-las invisíveis no banco até cada exercício ser reconstruído.

O bundle histórico em `sistemas/10-lab-exercicios-ds3/modo-aluno/` agora é apenas um redirecionamento para a plataforma integrada.

## Deploy pendente

1. executar `core/database/032_p80_3ds_ex04_release.sql` após validar o banco live;
2. configurar o segredo `AGV_PRIVATE_EXERCISE_RULES_V1` usando o pacote privado fornecido separadamente;
3. republicar `activity-progress` com JWT obrigatório;
4. fazer uma correção de teste com código incompleto e outra com solução válida;
5. somente então liberar o Exercício 04 pelo Console Professor.

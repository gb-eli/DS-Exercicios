# P8.1 — Pré-deploy da aula — v14.8.1

## Objetivo
Fechar inconsistências antes de publicar no GitHub e antes de ativar o corretor privado no Supabase.

## Correções

- Entregas de 80% a 99% não são mais contabilizadas como concluídas. O backend grava `status=in_progress`, `completion_source=server_private_validation_partial` e registra a evidência da entrega.
- Somente 100% marca `status=completed`. Uma atividade já concluída em 100% não é rebaixada por uma nova submissão pior.
- O painel do aluno diferencia **Entregue com pendências** de **Concluído**.
- O score exibido é invalidado assim que o aluno altera o código; uma nova correção é necessária para mostrar percentual novamente.
- O link GitHub é validado e normalizado no navegador e revalidado no servidor.
- A tela de entrega mostra checklist para salvar, commitar, fazer push e informar o repositório correto.
- `atividades/index.html` e `atividades/version.json` foram alinhados em 0.20.1.

## Segurança

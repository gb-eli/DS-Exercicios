# Atividade 03 - Requisitos funcionais e não funcionais na prática

Versão: 1.11.0  
Disciplina: Análise e Métodos para Sistemas

## Objetivo
Classificar RF, RNF e regras de negócio em um cenário aplicado, justificando cada escolha.

## Cenário
Sistema de Empréstimo de Chromebooks da escola.

## Checkpoints
1. Classificar as 8 afirmações.
2. Escolher a justificativa adequada para cada uma.
3. Validar a análise.
4. Concluir manualmente.

A atividade possui salvamento separado das Atividades 01 e 02.

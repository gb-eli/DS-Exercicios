# Pipeline de modelos 3D do Museu

Esta pasta está preparada para modelos `.glb`/`.gltf` otimizados. A v0.32.0 usa um visualizador procedural leve como fallback e não carrega modelos no início da página.

Requisitos para futuros modelos:
- licença e autoria registradas;
- malha otimizada e LOD;
- texturas WebP/KTX2 quando aplicável;
- escala e pivô normalizados;
- máximo recomendado de 2 MB por item no modo padrão;
- miniatura 2D obrigatória.

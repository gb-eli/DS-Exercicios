# Problemas corrigidos — Fliperama DS v0.33.0

## Inconsistências educacionais

- jogos apresentavam níveis diferentes de detalhe no guia;
- alguns módulos explicavam fases, enquanto outros mostravam apenas regras gerais;
- modos, dificuldades e qualidade gráfica não possuíam uma apresentação uniforme;
- história, curiosidades e código ficavam separados em formatos diferentes;
- não existia um exemplo de código curto e comparável para cada experiência;
- não havia classificação clara entre jogo, reconstrução, simulador e laboratório.

## Correções

- criada uma ficha única com os mesmos campos para os 18 jogos;
- progressão adaptada ao gênero: fases, mapas, ondas, rodadas, zonas ou missões;
- exemplos de código adicionados com escape de HTML;
- painel histórico recebeu fatos e curiosidades;
- painel de lógica passou a comparar pseudocódigo e código simplificado;
- conteúdo externo em JSON e cópia incorporada ao bundle mantêm o funcionamento offline.

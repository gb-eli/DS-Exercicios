# Changelog — Fliperama DS v0.32.0

- biblioteca local com 15 ilustrações SVG autorais;
- catálogo externo `museum/data/catalog.json`;
- coleções separadas de consoles, controles e sensores;
- visualizador 360° procedural em módulo independente;
- arraste por mouse/toque e giro pausável;

- atalhos da linha do tempo para catálogo e museu;

- Service Worker atualizado para v0.32.0;

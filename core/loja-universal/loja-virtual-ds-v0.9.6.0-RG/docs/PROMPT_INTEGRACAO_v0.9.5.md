# Prompt de Integração — Benchmark DS v0.9.5

Preserve o Benchmark DS Avançado como módulo compartilhado. Não copie resultados entre dispositivos. Use `window.DSAdvancedBenchmark.run()` para iniciar, `window.DSAdvancedBenchmark.report` para consultar o último relatório carregado e o evento `ds-advanced-benchmark-complete` para receber o resultado. Nunca instale pacotes Ultra/Realismo sem ação explícita do usuário.

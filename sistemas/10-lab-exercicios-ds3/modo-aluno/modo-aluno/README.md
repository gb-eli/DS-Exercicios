# Plataforma 3DS — Programação no Desenvolvimento de Sistemas — Aluno

Versão **v0.11.0**, atualizada em **07/08/2026**, com os Exercícios 01 a 08.

Esta versão aplica ao 3DS os padrões de experiência observados na Plataforma 2DS Front-End v0.5.29, sem copiar exercícios, respostas ou conteúdos de outra turma. A arquitetura própria do 3DS foi preservada, incluindo validação conceitual, autocompletar progressivo, execução/interação obrigatória, evidência com hashes e workspace exportável.

## Principais mudanças da v0.11.0

- página inicial clean separada da lista de atividades;
- botão principal **Ver atividades** e opção **Continuar último exercício** quando houver progresso;
- página **Atividades** com pesquisa, filtros, status, nível, tempo estimado e progresso;
- navegação por hash: `#home`, `#activities` e `#exercise-XX`;
- Modo VS Code com Explorador, referência completa, editor e painel inferior em abas;
- abas **Preview**, **Console**, **Terminal** e **Problemas**;
- checkpoints reais para código escrito, execução atual, interação e validação;
- cenários de comportamento derivados das exigências reais de cada exercício;
- referência completa em modo somente leitura, sem botão de copiar a solução inteira;
- terminal virtual e ZIP com a estrutura criada pelo aluno preservados;
- evidência verificável e autocompletar progressivo das versões anteriores preservados.

## Como abrir

Abra `index.html` por um servidor HTTP local ou publique somente a pasta `versao-aluno` no GitHub Pages. Não publique o pacote cumulativo completo, pois ele contém a versão Professor e materiais de referência.

## Conteúdo atual

Os Exercícios 01–05 trabalham principalmente HTML e organização de interfaces. Os Exercícios 06–08 trabalham CSS aplicado, Box Model, Flexbox e Grid. Arquivos de apoio permanecem no projeto e no ZIP, mas não são transformados indevidamente em produção obrigatória do aluno.

## Limitação atual

Os Exercícios 01–08 executam HTML/CSS/JavaScript no navegador. O terminal atual representa o workspace Web e o console de execução. Python ainda não está publicado nesta faixa e não é simulado como se houvesse um interpretador real.

# Migração de evidências — v28.1 para v29.0

## O que acontece com arquivos antigos

Nenhuma evidência antiga é apagada. Ao abrir uma aula, o Desafio DS recalcula o nível de confiança.

- arquivo com contexto completo e compatível: reconhecido;
- arquivo antigo sem atividade, disciplina ou versão: parcial;
- registro manual: declaração do aluno;
- arquivo de outra aula, turma ou ferramenta: incompatível;
- arquivo parcial confirmado pelo professor: validado pelo professor.

## Procedimento recomendado

1. Abra a aula que contém a evidência.
2. Consulte o selo de confiança.
3. Abra “Por que recebeu este status?”.
4. Quando necessário, selecione “Validar com professor”.
5. Gere a autorização correspondente no Validador EduAuth v29.
6. Registre uma justificativa curta.
7. Exporte novamente o relatório consolidado.

A validação vale apenas para aquela evidência, aula e atividade.

# Painel EduAuth Professor — v32.0

No pacote completo, abra `ABRIR_PAINEL_DO_PROFESSOR.html`.

## Liberar uma aula

1. Escolha turma.
2. Escolha disciplina.
3. Escolha aula.
4. Gere a senha coletiva atual de oito dígitos.
5. Informe aos alunos durante a janela de validade.

A senha não é fixa. Quando estiver expirada, o aluno deve solicitar uma nova nos comentários da atividade no Classroom.

A pasta privada não deve ser publicada no GitHub nem compartilhada com os estudantes.

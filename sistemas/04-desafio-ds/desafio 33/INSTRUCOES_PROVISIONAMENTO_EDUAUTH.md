# EduAuth v33.0 piloto — instruções do professor

## Iniciar uma aula

1. Publique somente `PUBLICAR_NO_GITHUB`.
2. Abra `ABRIR_PAINEL_DO_PROFESSOR.html` no pacote completo ou o `index.html` do painel separado.
3. Selecione turma, disciplina e aula.
4. Gere o código coletivo.
5. Informe os oito números à turma.

O código é vinculado à turma, disciplina e aula, vale uma hora e é solicitado somente no início. O piloto não exige nova autenticação durante explicações, simuladores, questões ou atividade final.

## Código expirado

O aluno será orientado a solicitar outro código nos comentários da atividade no Google Classroom.

## Arquivos privados

Nunca publique:

- `validator-config.js`;
- `CONFIGURACAO_PRIVADA_V33_0_PILOTO.json`;
- `PROFESSOR_PRIVADO_NAO_PUBLICAR`;
- o ZIP separado do painel do professor.

Não existe senha mestre fixa.

# Desafio DS v24.0 — Central de Código por Aula

Data: 30/07/2026

## Alterações

- Adicionada Central de Código sob demanda no Modo Guiado.
- As 14 aulas de Introdução à Programação receberam exemplos e projetos para copiar ou baixar.
- As 12 aulas de Programação Front-End da manhã e as 12 do Técnico Subsequente receberam projetos coerentes com cada etapa.
- As 14 aulas de Programação Mobile receberam exemplos web responsivos, Android Java/Kotlin, Swift, Rust e PWA.
- Adicionados botões para copiar código, baixar arquivo, baixar projeto ZIP, testar prévia web e abrir VS Code Web.
- Adicionadas abas de comandos, dependências, verificação, FAQ, erros comuns e limitações.
- Nenhuma dependência externa foi adicionada ao Desafio DS; o gerador de ZIP funciona no próprio navegador.
- Mantidos os recursos de EduAuth, perfis criptografados, Classroom, acessibilidade e responsividade.

## Limitações

- VS Code Web não abre automaticamente arquivos locais: o aluno precisa baixar, extrair e abrir a pasta.
- Projetos Android exigem Android Studio/SDK para o fluxo completo.
- SwiftUI/iOS exige Xcode em macOS.
- APIs externas podem falhar por indisponibilidade ou CORS.

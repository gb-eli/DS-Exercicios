# Desafio DS v33.0 — Piloto de conteúdo real

Plataforma educacional estática para GitHub Pages, com Modo Guiado, perfis locais, EduAuth offline, Classroom por disciplina, Central de Código e laboratórios internos.

## Escopo da versão

- 4 grupos de estudantes.
- 7 disciplinas.
- 121 IDs históricos preservados.
- 114 aulas ativas.
- 7 registros legados.
- 21 aulas piloto no novo padrão.
- 93 aulas preservadas no padrão v32 para comparação.
- 70 pacotes técnicos existentes preservados.

## Novo padrão pedagógico

Cada piloto possui:

- situação real;
- explicação do que é e para que serve;
- aplicação profissional;
- exemplo explicado;
- prática guiada;
- laboratório interno;
- quatro questões com feedback;
- atividade final e critérios;
- retomada e erros comuns;
- código copiável e baixável, quando aplicável;
- guia de VS Code, comandos e dependências, quando aplicável.

## Organização

- Manhã → 1º DS → Introdução à Programação e Análise e Método.
- Manhã → 2º DS → Programação Front-End e Inovação.
- Manhã → 3º DS → Programação no Desenvolvimento de Sistemas.
- Noite → 2º DS Subsequente → Programação Front-End e Programação Mobile.

## Autenticação

O código coletivo EduAuth possui oito dígitos, é vinculado à turma, disciplina e aula, vale por uma hora e é solicitado somente no início. Nenhuma etapa normal pede outro código.

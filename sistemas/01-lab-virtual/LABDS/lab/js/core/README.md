# Núcleo de carregamento

- `bootstrap.js`: carrega o mínimo necessário para abrir a plataforma.
- `resource-loader.js`: gerencia pacotes, manifestos, scripts e estilos sob demanda.
- `performance-manager.js`: seleciona economia, equilíbrio ou qualidade conforme configuração e capacidade do dispositivo.

Pacotes opcionais atuais: `shell`, `eduauth`, `terminal`, `export`, `learning` e `effects`.

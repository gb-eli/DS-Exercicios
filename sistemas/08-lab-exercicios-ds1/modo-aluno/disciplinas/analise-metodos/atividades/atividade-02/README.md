# Atividade 02 - Analisando requisitos de um sistema

Disciplina: Análise e Métodos para Sistemas  
Versão: 1.10.0  
Modo: Aluno

## Objetivo

Analisar um levantamento de requisitos e reconhecer necessidades claras, ambiguidades, conflitos, regras/restrições e informações faltantes antes de aprovar a especificação.

## Cenário

Sistema de Reserva de Laboratórios da escola. O cliente apresentou oito afirmações durante o levantamento. O estudante deve diagnosticar cada afirmação e selecionar as perguntas que precisam ser respondidas antes da implementação.

## Etapas

1. Classificar as oito afirmações do cliente.
2. Selecionar quatro perguntas essenciais para fechar as lacunas encontradas.
3. Validar a análise e revisar o feedback.
4. Concluir a atividade.

## Regra pedagógica

O exercício não repete a definição básica de requisitos. Ele trabalha leitura crítica de um briefing realista e preparação do levantamento para a próxima etapa da disciplina.

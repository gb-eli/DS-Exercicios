# Atividade 01 - Atores e Casos de Uso

Disciplina: Análise e Métodos para Sistemas
Versão: 1.9.5
Status: publicada

## Cenário

Sistema de Achados e Perdidos da escola.

## Objetivo

Identificar atores externos ao sistema e relacionar cada ator aos objetivos/casos de uso correspondentes.

## Atores esperados

- Aluno
- Funcionário
- Administrador

## Distratores intencionais

- Objeto encontrado
- Banco de dados

## Checkpoints

1. Identificar atores.
2. Relacionar casos de uso.
3. Validar o modelo.
4. Concluir manualmente.

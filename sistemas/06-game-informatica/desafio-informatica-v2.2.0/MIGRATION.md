# Migração de dados — schema 9

Ao desbloquear ou importar um perfil antigo, a plataforma cria os contêineres de aceites gerais, aceites por atividade e permissões sem apagar progresso, resultados ou preferências existentes.

O aluno deverá aceitar a versão atual antes de iniciar novas atividades. Recusar o novo termo não apaga o perfil; ainda é permitido exportar os dados existentes.

Resultados antigos sem `termsAcceptance` continuam legíveis para conferência, mas o relatório indicará que o aceite não foi validado naquela evidência.

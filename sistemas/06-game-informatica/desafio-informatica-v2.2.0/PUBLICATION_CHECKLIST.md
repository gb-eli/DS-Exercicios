# Checklist de publicação no GitHub Pages

- [ ] Substituir as chaves de desenvolvimento do EduAuth por configuração de produção.
- [ ] Executar `npm test` e guardar o relatório.
- [ ] Abrir `index.html` e `professor.html` por servidor HTTP.
- [ ] Testar criação, bloqueio, desbloqueio, exportação e importação de perfil.
- [ ] Testar aceite geral e regras específicas.
- [ ] Gerar PDF de aula e diagnóstico e conferir a seção de termos.
- [ ] Testar importação de resultado malicioso e arquivo corrompido.
- [ ] Testar Chrome Android, Brave Android, Chromebook e Edge.
- [ ] Testar modo offline depois do primeiro carregamento.
- [ ] Testar link do Google Classroom configurado.
- [ ] Revisar `contributors.config.json` antes de publicar qualquer nome.
- [ ] Submeter TERMS.md e PRIVACY.md à revisão institucional.
- [ ] Publicar e validar em janela anônima e rede externa.
- [ ] Confirmar que nenhum segredo, chave privada ou dado pessoal está no repositório.

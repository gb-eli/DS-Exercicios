# Changelog — Fliperama DS v0.26.0

## Fase 7.7 — Base Unificada

### Adicionado

- Service Worker versionado `v0.26.0`;
- página de diagnóstico técnico;
- fallback de armazenamento para localStorage e memória;
- tratamento de falha durante a inicialização;
- instruções atualizadas para publicação e abertura local;
- documentação da recuperação controlada.

### Alterado

- versão pública de `v0.23.0` para `v0.26.0`;
- fase pública para `Fase 7.7 — Base Unificada`;
- estratégia de cache para evitar páginas e scripts antigos;
- registro do Service Worker com atualização sem cache intermediário;
- VoxelCraft reclassificado de Jogável para Protótipo;
- pacote reorganizado com `index.html` na raiz.

### Preservado

- 105 módulos do bundle;
- 18 runtimes de jogos;
- 23 entradas de catálogo;
- 23 conjuntos de mídia;
- Phaser local;
- Three.js local do VoxelCraft;
- configurações, catálogo, museu e linha do tempo existentes.

### Ainda não corrigido

- bugs internos de fases e labirintos;
- dificuldade e IA dos jogos de tabuleiro;
- progressão impossível ou pontos de aprisionamento;
- museu 3D realista;
- falhas específicas do VoxelCraft.

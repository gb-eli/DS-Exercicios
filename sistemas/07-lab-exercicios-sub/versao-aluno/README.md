# Plataforma 2DS Sub — Área do Aluno — v0.1.42

Distribuição exclusiva para estudantes.

## Inclui
- Programação Front-End (FE01–FE07)
- Programação Mobile (MOB01–MOB04)
- modo guiado do aluno
- Modo VS Code com Explorer, referência protegida, editor do aluno, preview/terminal e velocímetro de progresso
- validação flexível e progresso independente por disciplina
- armazenamento limpo `state_v4` para impedir código fantasma vindo de versões antigas
- CSS consolidado no editor e no Modo VS Code

## Segurança de distribuição
Este pacote **não inclui o Painel do Professor**. Não existem `professor.html`, `professor.js` ou `professor.css`, nem rota/botão para abrir esse modo. Os metadados exclusivos de retomada do professor também foram removidos dos dados dos exercícios.

Abra `index.html`.

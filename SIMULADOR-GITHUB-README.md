# Como usar o Simulador GitHub

1. Entre no Console Professor.
2. Abra **Auditoria GitHub** e carregue o JSON privado dos 136 registros.
3. Registre as decisões desejadas.
4. Clique em **Exportar decisões**.
5. Abra **Simular baixa**.
6. Importe o JSON exportado no passo anterior.
7. Clique em **Simular com estado atual**.
8. Revise os itens **Aplicável**, **Bloqueado** e **Sem alteração**.
9. Se necessário, volte ao painel de auditoria e corrija a decisão.
10. Exporte o plano apenas quando quiser guardar a simulação para auditoria.

O simulador não possui função de aplicar alterações ao banco.

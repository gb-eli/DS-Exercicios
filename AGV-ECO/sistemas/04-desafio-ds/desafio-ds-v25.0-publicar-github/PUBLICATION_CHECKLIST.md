# Checklist de Publicação

- [ ] `index.html` está na raiz.
- [ ] Nenhuma pasta privada foi publicada.
- [ ] Nenhuma chave privada ou arquivo `.env` está presente.
- [ ] GitHub Pages abre por HTTPS.
- [ ] Termo aparece no primeiro acesso.
- [ ] Perfil pode ser criado, bloqueado, desbloqueado e exportado.
- [ ] EduAuth gera e valida o código da aula.
- [ ] Desafio inicia em modo competitivo e diagnóstico.
- [ ] Extrato de XP abre e mostra transações.
- [ ] Modo Guiado lista as 88 aulas corretamente.
- [ ] Central de Código copia e baixa projetos.
- [ ] Evidência contém registro do termo.
- [ ] Classroom abre em nova guia sem declarar entrega automática.
- [ ] Testes em celular e computador foram realizados.

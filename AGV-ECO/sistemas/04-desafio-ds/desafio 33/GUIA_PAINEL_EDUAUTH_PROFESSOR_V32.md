# Painel EduAuth Professor v32.0

O painel privado gera somente o código necessário para iniciar uma aula normal.

1. Extraia o ZIP do painel.
2. Abra `index.html`.
3. Escolha turma, disciplina e aula.
4. Selecione **Gerar código coletivo da aula**.
5. Compartilhe os oito números.

O código:

- vale por uma hora a partir da geração;
- funciona apenas para a turma, disciplina e aula selecionadas;
- pode ser usado pelos alunos da turma durante essa hora;
- não é solicitado novamente durante a atividade.

Não publique o painel nem sua configuração privada no GitHub.

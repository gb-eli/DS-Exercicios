DESAFIO DS — v19.0

PUBLICAÇÃO
1. Apague os arquivos da versão anterior no repositório.
2. Envie todo o conteúdo desta pasta para a raiz.
3. Confirme que index.html está na raiz.
4. Aguarde o GitHub Pages concluir a publicação.
5. Abra em aba anônima para evitar cache antigo.

NOVO: MODO GUIADO
- 86 aulas organizadas por turma e disciplina;
- código curto por aula;
- explicações extras A–J;
- laboratórios e ferramentas;
- tempo mínimo de 25 minutos ativos;
- inatividade registrada;
- liberação antecipada pelo professor;
- exportação da evidência;
- botão para o Google Classroom.

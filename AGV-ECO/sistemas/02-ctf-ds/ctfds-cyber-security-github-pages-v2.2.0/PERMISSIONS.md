# Permissões e recursos do dispositivo

**Manifesto:** 1.0.0

A versão 2.2.0 não exige câmera, microfone, localização, Bluetooth ou sensores.

| Recurso | Uso | Obrigatório | Alternativa |
|---|---|---:|---|
| Arquivos | Importar backup escolhido pelo aluno | Não | Criar novo perfil ou continuar sem salvar |
| Download | Exportar evidência e backup | Não | Manter o progresso local e exportar depois |
| Área de transferência | Copiar código EduAuth por ação do aluno | Não | Digitar manualmente |
| Síntese de voz | Ler código EduAuth quando solicitado | Não | Ler visualmente |
| Armazenamento persistente | Tentar reduzir remoção automática pelo navegador | Não | Fazer backup periódico |
| Notificações do sistema | Não utilizadas | Não | Mensagens internas na página |

Nenhum arquivo é lido além do arquivo selecionado pelo usuário. A plataforma não lê automaticamente a área de transferência.

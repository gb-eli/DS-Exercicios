# Permissões e Recursos do Dispositivo

**Manifesto:** 1.0.0

O Desafio DS v25.0 não solicita câmera, microfone, localização ou sensores.

## Área de transferência

- **Finalidade:** copiar código, comandos, comprovantes e códigos-base.
- **Momento:** somente após o aluno selecionar Copiar.
- **Alternativa:** seleção e cópia manual.

## Arquivos selecionados

- **Finalidade:** importar perfil ou arquivo escolhido pelo usuário.
- **Limite:** somente o arquivo selecionado.
- **Alternativa:** continuar sem importar.

## Download

- **Finalidade:** exportar evidências, backup e projetos.
- **Armazenamento:** pasta definida pelo navegador.
- **Alternativa:** copiar conteúdo quando disponível.

## Armazenamento persistente

- **Finalidade:** reduzir a chance de remoção automática dos perfis criptografados.
- **Obrigatoriedade:** opcional.
- **Alternativa:** manter backup do perfil e das evidências.

## Tela cheia

- **Finalidade:** ampliar o espaço da atividade.
- **Obrigatoriedade:** opcional.
- **Situação atual:** não é solicitada automaticamente.

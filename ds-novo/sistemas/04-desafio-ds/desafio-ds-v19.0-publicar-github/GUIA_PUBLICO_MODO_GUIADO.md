# Modo Guiado — uso na plataforma

O Modo Guiado é uma experiência paralela ao Desafio DS para acompanhar as aulas.

## Fluxo do aluno

1. Escolher **Modo Guiado**.
2. Informar nome, turma e disciplina.
3. Selecionar a aula disponível.
4. Digitar o código curto informado pelo professor.
5. Realizar as etapas em sequência.
6. Usar explicações extras quando necessário.
7. Concluir prática, laboratório, desafio e revisão.
8. Atingir o tempo mínimo de 25 minutos ativos ou obter liberação docente.
9. Exportar a evidência.
10. Abrir o Google Classroom e anexar o arquivo.

## Explicações extras

- A — resumo objetivo;
- B — explicação detalhada;
- C — exemplo prático;
- D — aplicação na vida real;
- E — analogia;
- F — explicação visual;
- G — passo a passo;
- H — comparação entre tecnologias;
- I — erros comuns;
- J — desafio avançado.

## Armazenamento

O progresso fica salvo no navegador utilizado. Limpar os dados do site ou trocar de equipamento pode remover o progresso local.

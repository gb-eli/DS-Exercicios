# Finalidade Educacional e Uso Autorizado

Todo o conteúdo desta plataforma foi criado para aprendizagem, prática segura e desenvolvimento de competências de Informática Empresarial e tecnologia.

## Uso permitido

- realizar as atividades propostas pelo professor;
- praticar em ambientes locais, simulados ou expressamente autorizados;
- testar recursos quando isso fizer parte da aula;
- comunicar falhas de forma responsável;
- produzir e entregar evidências escolares.

## Uso não permitido

- alterar respostas, tempo, XP, progresso ou resultados para obter vantagem;
- acessar contas, redes, equipamentos ou dados de terceiros;
- explorar falhas fora do escopo da atividade;
- publicar dados pessoais ou credenciais;
- utilizar técnicas aprendidas para causar dano, fraude ou acesso não autorizado.

Quando uma atividade envolver segurança, o conteúdo ofensivo deve ser acompanhado de prevenção, detecção, mitigação, ética e limites legais.

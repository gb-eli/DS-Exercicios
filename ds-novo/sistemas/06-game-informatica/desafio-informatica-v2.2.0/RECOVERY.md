# Recuperação administrativa

A senha antiga do aluno nunca é exibida. Cada perfil possui uma chave de dados protegida pela senha do aluno e um envelope adicional preparado para recuperação pelo professor.

Nesta versão, o fluxo final depende do EduAuth Professor e de sua chave privada de recuperação. Até o provisionamento, as alternativas seguras são importar um backup válido ou criar novo perfil, preservando o arquivo anterior para análise.

Nunca adicione senha universal, chave privada ou credencial de emergência ao JavaScript publicado.

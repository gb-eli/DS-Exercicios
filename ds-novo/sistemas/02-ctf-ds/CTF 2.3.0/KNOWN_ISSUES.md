# Problemas conhecidos e limitações

- O GitHub Pages não fornece backend, auditoria central ou confirmação real de entrega no Classroom.
- O EduAuth está estruturalmente integrado, mas ainda usa chaves de teste e não deve proteger atividades oficiais até o provisionamento de produção.
- Perfis podem ser removidos pelo navegador; backups continuam recomendados.
- A carteira detecta adulterações simples, mas não é absolutamente inviolável contra quem controla o navegador.
- Fontes e referências externas exigem internet para abrir.
- A proficiência exibida é estimativa formativa e requer revisão do professor.
- O uso simultâneo do mesmo perfil em duas abas não possui sincronização autoritativa; para evitar conflitos, mantenha apenas uma aba desbloqueada por vez.

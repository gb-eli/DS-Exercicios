# Plataforma 2DS Front-End — Aluno — v0.5.30

Esta pasta é uma aplicação independente.

## Publicação recomendada

Publique esta pasta por HTTPS no GitHub Pages. O login local utiliza Web Crypto para proteger a senha e criptografar a sessão.

- Modo: **Aluno**
- Exercícios incluídos: **01 a 28**
- Atualização do pacote preservado: **07/08/2026**

## Novidades

- página inicial para escolher o exercício;
- criação de usuário e login local;
- sessão criptografada por até 5 dias;
- bloquear, desbloquear, trocar usuário e sair;
- exportação de logs em JSON e CSV;
- retomada do último exercício;
- indicador ao vivo da completude do código;
- porcentagem aproximada restante;
- aviso de erro de sintaxe, arquivo em construção, quase completo ou validado;
- validação flexível e diagnóstico detalhado após três tentativas.

## Limite de segurança

A autenticação é local e não substitui uma conta validada por servidor. Ela identifica usuários e preserva sessões no dispositivo usado.

### Limite técnico honesto

Esta plataforma é de Programação Front-End e seus exercícios publicados usam HTML, CSS e JavaScript. O HTML/CSS/JS é executado de verdade pelo navegador. O terminal manipula o sistema de arquivos virtual do exercício e não finge executar Python, Java, C ou outras linguagens ausentes deste projeto. Plataformas que ensinam essas linguagens devem conectar o mesmo fluxo visual a um runtime real compatível.

# Sistema visual — v0.35.2

A série v0.35.x modernizou os 18 jogos atuais em três blocos. O Bloco 3/3 cobre State Quest RPG, Ponte 8→16 Bits, Corredores Raycast, Setor Poligonal 94, Câmeras em Evolução e VoxelCraft DS.

As camadas de palco usam CSS sem eventos de ponteiro. Phaser/WebGL continuam responsáveis pelo playfield. Perfis Histórico/Baixo reduzem custo; Médio/Alto/Ultra elevam profundidade, emissivos, ambientação e detalhe.

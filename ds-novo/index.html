Primeiro acesso

Crie sua senha pessoal

Por segurança, o CGM é apenas uma senha temporária. Defina uma nova senha para liberar os exercícios.

• pelo menos 8 caracteres • pelo menos uma letra • pelo menos um número

Importante

Não reutilize seu CGM

Sua senha deve ser pessoal. Não compartilhe com colegas e evite usar o mesmo código de outros serviços.

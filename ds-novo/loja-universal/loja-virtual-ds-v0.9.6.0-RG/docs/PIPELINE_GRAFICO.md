# Pipeline gráfico

1. Produzir ou revisar o asset-fonte.
2. Exportar SVG para UI e arte vetorial.
3. Gerar WebP 512×512 para catálogo.
4. Gerar PNG/WebP 256×256 para materiais.
5. Registrar no manifesto.
6. Validar dimensões, transparência, peso e referências.
7. Carregar somente quando o módulo correspondente for solicitado.

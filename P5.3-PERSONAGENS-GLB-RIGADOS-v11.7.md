# P5.3 — Personagens GLB Rigados — v11.7

## Objetivo
Evoluir o Lobby 3D para personagens com esqueleto e animação esquelética mantendo o fallback leve.

## Implementado
- `lobby/assets/models/agv-avatar-rig-v1.glb`: glTF 2.0 binário próprio do projeto.
- Esqueleto com Root, Hips, Torso, Head, braços e pernas.
- Skinning por joints/inverse bind matrices.
- Clips no próprio GLB: Idle, Walk, Run, Jump e Wave.
- Loader mínimo dedicado ao asset AGV (`rigged-avatar.js`), sem dependência de CDN.
- `AnimationMixer` e crossfade entre idle/walk/run.
- Jump e Wave como ações one-shot.
- Avatar procedural permanece fallback obrigatório.
- Equipamentos fracos/mobile podem permanecer no procedural para estabilidade.

## Segurança
A alteração é apenas de renderização. O GLB não recebe autoridade de banco, release, progresso, carteira ou moderação. A presença continua passando pela Edge Function protegida.

## Supabase
Nenhuma migration, SQL ou Edge Function nova é necessária para P5.3.
